Authentication

Create a key on the API keys page. Send it in either header:

x-api-key: itk_<48 hex chars>
Authorization: Bearer itk_<48 hex chars>

A user key manages its own issues and cannot change a status. An admin key has full access.

Web API — events

Webhooks POST to your URL on: issue.created, issue.updated, issue.status_changed, issue.done, issue.deleted. Configure them on the Webhooks page.

Examples

Conventions: ?limit&offset pagination, ?sort&order, errors as { "error": { "code", "message" } }.

curl "$BASE/v1/issues?status=pending&limit=10" \
  -H "x-api-key: $KEY"

curl -X PATCH "$BASE/v1/issues/<id>" \
  -H "x-api-key: $ADMIN_KEY" -H "content-type: application/json" \
  -d '{"status":"done","admin_note":"Fixed in v1.4"}'
