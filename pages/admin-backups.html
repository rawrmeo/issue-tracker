Backups

The system snapshots every issue by itself. Restoring puts the board back exactly as it was.

Automatic backups on

A snapshot is taken automatically whenever an issue is filed, changed or deleted — at most one an hour, so it can never flood. The newest 30 are kept and older ones fall away on their own.

Saved snapshots 0

Download saves a JSON copy. Restore replaces the current issues with that snapshot — a safety snapshot is taken first, so a restore can itself be undone.
