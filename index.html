Connect your database

This tracker stores everything in Supabase. There are three short steps before you can sign in.

  1. Create a free project at supabase.com
  2. Open SQL Editor → New query, paste the whole of supabase/schema.sql, and press Run.
  3. Open Settings → API and paste your Project URL and anon public key into supabase-config.js, then reload this page.

Detailed walkthrough with screenshots-by-description: SETUP.md
